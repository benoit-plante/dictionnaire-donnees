# Essai du 2026-10-13 : Qwen 2.5 7B sur la base fictive

Premier essai réel de l'enrichissement (étape 11), sur la base fictive `etude-sommeil.sav` (29 variables). Données entièrement fictives.

## Conditions

| Élément | Valeur |
|---|---|
| Modèle | `qwen2.5:7b-instruct-q4_K_M` (4,7 Go), servi par Ollama 0.35.1 |
| Matériel | NVIDIA GeForce RTX 5060 Laptop, 8 Go |
| Prompt | `variables-v1` |
| Paramètres | température 0, graine 42, blocs de 12 variables (3 blocs) |
| Durée | 123 s pour les 3 blocs ; 1,4 s pour une relance (aucun bloc renvoyé) |

## Résultats

**Format : sans faute.** Les 3 blocs ont été acceptés au premier essai : JSON conforme au schéma, mêmes variables, même ordre. Aucun signal d'invention (citation, seuil, nom d'instrument).

**Libellés (29) : bons dans l'ensemble.** Exemples : « DDN » devient « Date de naissance », « ANX controle inquietude » devient « Contrôle inquiétude », « Q5 energie matin » devient « Énergie matin ». Défauts :
- accents pas toujours rétablis (« Sommeil reparateur », « Reveils nocturnes ») ;
- `sommeil_q7`, qui n'a pas d'étiquette dans le fichier, reçoit le libellé de sa voisine `sommeil_q8` (« Routine sommeil ») : une supposition présentée comme un fait.

**Descriptions (29) : correctes mais pauvres.** Souvent une reformulation du libellé (« Réponse à la question 1 sur l'endormissement »). Aucune n'invente d'information grave ; `anx7` suppose un lien avec l'anxiété à partir du préfixe.

**Incohérences signalées (« issues ») : surtout du bruit.** Classement manuel des 48 signalements :

| Catégorie | Nombre approx. | Exemples |
|---|---|---|
| Justes, mais déjà calculés par l'outil | 13 | « Valeur 999 probablement manquante » (`age`), « Identique à heures_sommeil » |
| Faux | 18 | « Code 9 observé sans étiquette » pour `sommeil_q2`, `q4`, `q5` ; « -9 non déclaré » pour `anx1` à `anx6`, où il est déclaré ; corrélation négative pour `sommeil_q1` |
| Bruit (consigne du prompt recopiée) | 17 | « Effectifs trop petits remplacés par « masqué » », « Aucune valeur transmise » |

Aucun signalement juste n'apportait une information que l'outil n'avait pas déjà.

## Conclusions

1. La chaîne fonctionne de bout en bout sur la carte graphique, avec un format de réponse fiable.
2. Les libellés et descriptions sont utiles comme propositions à réviser.
3. Les « issues » de l'IA nuisent : elles mêlent des erreurs à des répétitions des anomalies déterministes. Un relecteur pourrait valider une affirmation fausse.

## Pistes (à décider)

- Retirer la demande d'incohérences du prompt pour la v0.1 : l'outil les calcule déjà, sans erreur.
- Prompt `variables-v2` : rétablir les accents ; quand le fichier n'a pas d'étiquette, le dire dans la description plutôt que deviner à partir des voisines ; ne jamais recopier les consignes.
- Comparer avec `mistral:latest` sur la même base, avec le même prompt.
